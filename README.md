# Barrel Siege — Forge 26.2

Событие раз в 15 минут создаёт в обычном мире защищённую бочку в радиусе 64 блоков от случайного игрока. Сначала нужно уничтожить три волны мобов: 8, 12 и 16. Пока охрана жива, бочку нельзя открыть или сломать. После последней волны она заполняется незеритовой бронёй и оружием, элитрами, тотемами, алмазами, незеритовыми слитками и прочим лутом.

## Сборка

1. Установите JDK 25 и задайте `JAVA_HOME` на него.
2. Скачайте официальный MDK Forge `26.2-65.1.2`. Скопируйте из него только `gradlew.bat`, `gradlew`, папку `gradle/` и `gradle/wrapper/` в эту папку.
3. В PowerShell из этой папки выполните `./gradlew.bat build`.
4. Готовый мод будет в `build/libs/barrel-siege-1.0.0.jar`; поместите его в папку `mods` клиента и сервера с Forge 26.2.

## Команды для OP

* `/barrelsiege start` — мгновенно запускает событие.
* `/barrelsiege interval <минуты>` — меняет интервал до перезапуска сервера.

Координаты бочки публикуются в чат всем игрокам. Событие работает только в обычном мире (Overworld).

## Сборка без места на компьютере (GitHub)

В проект уже добавлен файл `.github/workflows/build.yml`. Он собирает мод на сервере GitHub, поэтому JDK и Forge не нужно скачивать на компьютер.

1. Создайте пустой репозиторий на GitHub через браузер.
2. Загрузите в него **всё содержимое** этого архива, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** → **Build Barrel Siege** → **Run workflow**.
4. Когда сборка закончится, откройте её и скачайте внизу `Barrel-Siege-Forge-26.2`. Внутри будет файл `barrel-siege-1.0.0.jar`.
